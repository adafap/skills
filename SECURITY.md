# Security policy

Do not open a public issue containing employment documents, names, health information, account data, credentials, or other personal facts.

Report a vulnerability through GitHub's private vulnerability reporting for `adafap/skills`. Include the affected Skill, version or commit, minimal reproduction, and security effect. Redact all user and employer identities.

For a potentially incorrect legal deadline or rule, identify the Skill and link the current official primary source. Treat the existing rule as unverified until reviewed.
